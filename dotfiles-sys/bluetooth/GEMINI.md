# Project Context: Bluetooth Configuration and Maintenance

## Directory Overview
This directory is used to manage and troubleshoot Bluetooth configuration, specifically focusing on resolving connectivity issues for peripheral devices like keyboards on an Arch Linux system. It serves as a repository for investigation notes, command outputs, and configuration management scripts.

## Key Files
- `MEMORY.md`: A personal, project-specific index containing notes, command outputs, and troubleshooting history. It is NOT for commitment to the repository.
- `GEMINI.md`: This file, containing structural instructions and project-level context.

## Usage
- Bluetooth device management (trusting devices, checking status).
- Power management tuning via `udev` rules.
- System configuration adjustment (BlueZ daemon, kernel module management).
- Troubleshooting logs and diagnostic outputs.
