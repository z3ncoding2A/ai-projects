# Project Instructions

This project is a documentation repository containing system hardware information and a list of AI models prioritized by their compatibility with the local system.

## Project Context
- **Hardware Profile:** The system is an Arch Linux workstation ("ai-arch") equipped with an Intel Core i5-14400F processor, an NVIDIA GeForce RTX 5060 (GB206) GPU, and 16GB of DDR4 RAM.
- **Primary Goal:** Maintain a list of 25 local/offline-compatible AI models, ranked from best to worst based on the hardware profile and performance in tools like LM Studio.

## Documentation Structure
- `HARDWARE.md`: Detailed hardware report generated by HardInfo.
- `MODELS_LIST_INFO.md`: Requirements and instructions for the 25-model list.
- `EXAMPLE-FORMATTING.md`: Design patterns for the model list.

## Workflow Conventions
- When updating the AI model list, ensure the models are compatible with the hardware described in `HARDWARE.md`.
- Model descriptions should be clean, simple, and explain the specific use cases for each model (e.g., coding, troubleshooting, general chat).
- Prioritize models available on Hugging Face that can be run locally.
- Recommend GGUF quantizations (Q4_K_M or Q5_K_M) as the preferred format for local inference.
- Use a professional software developer design pattern for lists, combining the clarity of Example 1 and the structured hierarchy of Example 2 from `EXAMPLE-FORMATTING.md`.
