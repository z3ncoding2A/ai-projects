# Raspberry Pi Projects

## Directory Overview
This directory is intended for storing projects, scripts, documentation, and other materials related to Raspberry Pi. Currently, it serves as a fresh workspace for upcoming Raspberry Pi development.

## Key Files
- `GEMINI.md`: This file, which provides context and instructions for the Gemini CLI when working within this directory.
- `ROADMAP.md`: Outlines the current objectives, planned projects, and direction for the Raspberry Pi development workspace.
- `SSH.md`: Contains the authentication credentials and IPv4 addresses (ethernet and wireless) for direct SSH access to the Raspberry Pi 5 (`z3nberry`).

## Usage
This directory will be used to organize and manage Raspberry Pi related tasks and codebases. As new files and subprojects are added, this documentation should be updated to reflect the new structure and guidelines.
