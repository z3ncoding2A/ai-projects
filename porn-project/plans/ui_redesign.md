# UI Redesign Plan: Cinematic Dark with Sidebar

## Objective
Completely redesign the HTML grid generated by `generate_grid.py` to match a modern, "Cinematic Dark" aesthetic (Netflix/Plex style) with a persistent sidebar navigation and a sleek, highly visual video grid.

## Key Files & Context
- `generate_grid.py`: The `write_html_grid` function embeds the entire HTML/CSS/JS template. This function will be modified to inject the new template.

## Proposed Solution (HTML/CSS/JS Architecture)
1. **Layout Structure (CSS Grid/Flexbox)**
   - Introduce a true `display: flex;` layout at the `<body>` level, splitting the UI into a `sidebar` (left, fixed width of 240px) and a `main-content` area (right, flexible, `flex: 1`).
2. **Sidebar Navigation**
   - Move the category tabs ("Main List", "Public", "Most Liked", etc.) into a vertical list in the sidebar.
   - Add modern hover states (e.g., slight background lightening, glowing left border for the active state).
   - Place "Export" and "Blacklist" buttons at the bottom of the sidebar to keep them out of the main viewing area.
3. **Top Search/Filter Bar (Glassmorphic)**
   - Float the search input, sort dropdown, and result count at the top of the `main-content` area.
   - Use `backdrop-filter: blur(12px);` to give it a modern frosted glass effect as users scroll down.
4. **Cinematic Dark Theme**
   - **Backgrounds**: Deep, rich blacks (`#050505`) for the main canvas, slightly elevated blacks (`#121212`) for the sidebar and cards.
   - **Accents**: Replace the current flat orange with vibrant neon accents (e.g., `#e50914` for primary actions and `#3498db` for selections) to highlight the active tab, borders on hover, and key UI elements.
   - **Typography**: Import a modern, clean Google Font like 'Inter' or 'Outfit' with varied weights (bolder titles, softer grays for metadata).
5. **Video Cards & Hover Effects**
   - **Images**: Maintain the 16:9 aspect ratio but add a subtle `border-radius: 8px`.
   - **Hover**: Smoothly scale the card up (`transform: scale(1.05)`) and add a soft glowing drop-shadow. The video preview rotation logic remains intact but benefits from the sleeker card container.
   - **Categorization Actions**: Hide the "P", "L", "A", "M", "Reset", "Delete" buttons by default. Reveal them on card hover with a clean slide-up animation to reduce visual clutter when just browsing.
6. **Javascript Updates**
   - Update the `setTab` function to toggle active states on the new sidebar elements instead of the old horizontal tabs.
   - Ensure the `createVideoCard` function outputs the new, cleaner HTML structure.

## Implementation Steps
1. Use `replace` on `generate_grid.py` to swap out the `html_start` string (lines ~365 to ~875).
2. The replacement will contain the entirely rewritten HTML, CSS (`<style>`), and Javascript (`<script>`) blocks as outlined above.

## Verification & Testing
- Run `python generate_grid.py` to produce `z3ncoding_videos_grid.html`.
- Open the HTML file in a browser to confirm:
  - The sidebar is present and functional.
  - The search and sort functions work correctly.
  - Video cards scale smoothly on hover and display category buttons.
  - Infinite scrolling still functions correctly within the new `main-content` container.
